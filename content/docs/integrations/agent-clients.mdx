# Agent Client Integration

`eye` uses a local stdio command, so the integration surface is simple across MCP-aware tools.

## Codex

```bash
codex mcp add eye -- npx -y eye-mcp
```

## Claude Code

```bash
claude mcp add --scope project eye -- npx -y eye-mcp
claude mcp list
claude mcp get eye
```

## Generic `.mcp.json`

```json
{
  "mcpServers": {
    "eye": {
      "command": "npx",
      "args": ["-y", "eye-mcp"]
    }
  }
}
```
